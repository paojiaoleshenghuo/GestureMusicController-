# GestureMusicController-
在root权限下，本地识别手势控制手机的歌曲播放
这是一款纯本地、完全运行在后台的安卓手势音乐控制工具。
基于 Google **MediaPipe Tasks Vision** 框架开发，无需联网，不依赖任何云端计算，在彻底保护隐私的前提下，利用前置摄像头实现高精度的手部关键点追踪和手势分类。

配合 **Root 权限**，能够在系统最底层全局模拟按键输入，无论是网易云、QQ音乐、Spotify 还是任何音视频播放器，都能实现完全无感的后台多媒体控制。

## 功能特性

- **纯后台静默运行**：以 CameraX 无界面 (Headless) 模式绑定前置摄像头，将性能损耗降至最低。
- **纯本地极速计算**：直接调用 MediaPipe 的手部侦测本地模型 `hand_landmarker.task`。
- **高精度动态生理比例算法**：告别传统的绝对像素距离阈值！基于“手腕-中指掌指关节”的掌长作为动态比例尺，不受手部距摄像头远近影响：
  - **握拳 (暂停/播放)**：需稳定握拳超过 **2 秒**，彻底防误触。
  - **左/右挥手 (上一曲/下一曲)**：动作判定要求极高的连贯性。右向左跨度要求超过 0.8s (上一曲)；左向右跨度大于 0.4s (下一曲)，挥手幅度必须超过屏幕的 25%。
- **全局生效**：内置底层 `RootCommandExecutor` 发送全局 `input keyevent` 多媒体按键指令，穿透所有应用层级直接对系统进行全局媒体控制。
- **极简体积**：使用 ProGuard R8 深度混淆剥离无用代码并移除多余 ABI 架构包，极限压缩应用体积。

## 权限要求

1. **相机权限 (Camera)**：用于静默捕获图像。
2. **震动权限 (Vibrate)**：动作识别成功后给出微弱震动反馈。
3. **Root 权限**：用于绕过 Android 系统限制，向系统底层的 `/system/bin/input` 注入全局媒体按键。

## 环境要求与编译

- **最低 SDK**：Android 7.0 (API 24)
- **目标 SDK**：Android 14 (API 34) (已实测完美兼容 Android 17 的后台机制)
- 仅支持 64 位 (`arm64-v8a`) 架构处理器的安卓设备。

自行编译请使用 Android Studio 或直接在根目录执行 Gradle 命令：

```bash
./gradlew assembleDebug
```

## 使用说明

1. 授予应用 **相机** 和 **Root** 权限。
2. 点击界面上的【开启手势识别服务】按钮，此时应用会转入后台无声运行。
3. 把手机放在一边（如桌面支架上），对着前置摄像头做出：
   - ✊ **握紧拳头（保持2秒）**：播放或暂停。
   - 🤚 **从右向左缓慢挥手**：上一曲。
   - 🤚 **从左向右挥手**：下一曲。
